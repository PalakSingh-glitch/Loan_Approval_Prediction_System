# Loan Approval Prediction System using Machine Learning

## Project Overview
This project predicts whether a loan application will be Approved or Rejected using Machine Learning techniques. The system analyzes applicant details such as income, education, credit history, marital status, loan amount, and property area to make predictions. The final model is deployed using Streamlit for real-time loan approval prediction.

- Logistic Regression Accuracy: 78.8%
- Random Forest Accuracy: 77.2%
